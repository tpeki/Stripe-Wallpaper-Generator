# Sub_sprites.py

**sub_sprites.py** は大きく分けると、**スプライトセット管理、SPRファイル入出力、ビットマップとの相互変換、スプライトパターン処理、パレット処理、GUIによる取り込み**の機能を持っています。ファイルは871行あります。

## 1. クラス

| クラス      | 概要                                                         |
| ----------- | ------------------------------------------------------------ |
| `SpriteSet` | スプライトのセットを管理する共有データクラス。セット名、説明、スプライト辞書、有効スプライト一覧、角度補正情報などを保持する。 |

### `SpriteSet` のメソッド

| メソッド                                 | 概要                                                     |
| ---------------------------------------- | -------------------------------------------------------- |
| `__init__()`                             | 空のスプライトセットを初期化                             |
| `load_internal()`                        | `INTERNAL_SET` に定義された内蔵スプライトを読み込む      |
| `set_pattern(name, patterndic, desc='')` | スプライト辞書をセットし、セット名・説明・有効一覧を設定 |
| `list()`                                 | 登録されているスプライト名の一覧を返す                   |
| `get(label)`                             | 指定名のスプライトデータを取得                           |
| `size(label)`                            | 指定スプライトの `(width, height)` を取得                |

`SpriteSet` は、このモジュールの中心となるデータ管理クラスです。

------

# 2. SPRファイル関連

| 関数                               | 概要                                                         |
| ---------------------------------- | ------------------------------------------------------------ |
| `sprfile_list(directory, zfile)`   | 指定ディレクトリから `.spr` ファイル一覧を取得。ZIP内も対象にでき、最後に内蔵セットを追加 |
| `str_to_tuple(s)`                  | SPR形式の1行を内部データ形式 `(ビットパターン, 色)` またはコマンドに変換 |
| `load_spr(file, directory, zfile)` | SPRテキストファイルを読み込み、スプライト辞書に変換          |
| `save_spr(file, pdic)`             | スプライト辞書をSPRファイルとして保存                        |
| `dtos(data)`                       | 内部データをSPR用の文字列へ再帰的に変換                      |
| `compress(buf)`                    | `rep` / `turnover` マクロを使ってSPRデータを圧縮             |

特に `load_spr()` と `save_spr()` がSPR形式との入出力の中心です。SPR形式自体は、複数のスプライト定義を1ファイルに格納でき、`turnover` と `rep<n>` の圧縮コマンドを持つ設計になっています。

### `compress()` の内部処理

`compress()` は単純な連長圧縮ではなく、動的計画法を使って、

- そのまま1行出力
- `rep<n>` による繰り返し
- `turnover` による反転繰り返し

のうち、**文字列長が最も短くなる組み合わせを選択**しています。

------

# 3. ビットマップ → SPR変換

| 関数                               | 概要                                                         |
| ---------------------------------- | ------------------------------------------------------------ |
| `reduce_cpr(img, colors_per_row)`  | 画像を「1行あたり最大N色」に減色                             |
| `conv_spr(img, transparent_color)` | ビットマップ画像をSPR形式の文字列データに変換                |
| `read_and_conv(file, trans)`       | 画像ファイルを読み込み、サイズ制限・変換を行ってSPR内部データにする |

### `reduce_cpr()`

画像をNumPy配列に変換し、**各行ごとに指定色数まで減色**した後、さらに全体を16色に制限します。

### `conv_spr()`

このモジュールの中ではかなり重要な変換関数です。

画像の各行について、

1. 使用色を調べる
2. 最大16色に制限
3. 各色についてビットマスクを生成
4. 16進数のビットパターンに変換
5. 色情報と組み合わせてSPR文字列にする

という処理を行います。

------

# 4. スプライトパターン操作

| 関数                                | 概要                                                         |
| ----------------------------------- | ------------------------------------------------------------ |
| `and_pat(orig, pat, n)`             | 多値ビットパターンを合成し、指定番号のパターンで上書き       |
| `sprite_pattern(name, sprites)`     | SPR内部データを展開して、実際の1行ごとのビットパターンに変換 |
| `get_sprite_by_name(name, sprites)` | 名前からスプライト画像を直接取得                             |

### `sprite_pattern()`

ここも中心的な関数です。

SPRデータに含まれる、

- 通常のビットパターン
- 複数色のビットパターン
- `turnover`
- `rep<n>`

を解釈して、最終的な

```text
[
    (bit_pattern, colors),
    (bit_pattern, colors),
    ...
]
```

という描画可能な形式に展開します。

つまり、

**SPRファイルの圧縮・定義形式 → 実際に描画するパターン**

への変換を担当しています。

------

# 5. SPR → ビットマップ

| 関数                               | 概要                                         |
| ---------------------------------- | -------------------------------------------- |
| `draw_oneline(dr, pat, colors, y)` | スプライトの1行をPillowで描画                |
| `sprite_image(pat)`                | 展開済みスプライトパターンからRGBA画像を生成 |

`draw_oneline()` が1行を描画し、`sprite_image()` がそれを全行について実行して画像化します。

したがって変換関係としては、

```text
画像
  ↓
conv_spr()
  ↓
SPR内部データ
  ↓
sprite_pattern()
  ↓
展開済みパターン
  ↓
sprite_image()
  ↓
PIL Image
```

という流れになります。

------

# 6. パレット関連

| 関数                                  | 概要                                                 |
| ------------------------------------- | ---------------------------------------------------- |
| `palette_extract(img, max_colors=16)` | 画像から使用頻度の高い色を最大16色抽出               |
| `palette_draw(palette, trans=None)`   | パレットを小さな画像として描画                       |
| `palette_img(img, trans=None)`        | 画像からパレットを抽出し、パレット画像と色一覧を返す |

`palette_draw()` はGUI上で透明色を選択するためのパレット表示にも使われています。

------

# 7. プレビュー関連

| 関数                                    | 概要                                                         |
| --------------------------------------- | ------------------------------------------------------------ |
| `xy_keep_aspect(img)`                   | `PREVIEW_SIZE=(272,240)` に収まるようアスペクト比を維持したサイズを計算 |
| `update_preview(wn, img, cpr, trans)`   | 減色・リサイズした画像とパレットをGUIに表示                  |
| `check_transparent(wn, palette, trans)` | 指定透明色がパレットに存在するか確認し、無ければ最後の色を透明色候補にする |

この辺りはSPR変換そのものより、**画像取り込みGUIのプレビュー機能**に属します。

------

# 8. GUIによるスプライト取り込み

| 関数                               | 概要                                                   |
| ---------------------------------- | ------------------------------------------------------ |
| `create_spr(spriteset, directory)` | GUIを表示して画像からスプライトを作成・登録            |
| `bulk_import(directory)`           | 指定フォルダ内の画像を一括してスプライトとして取り込む |

### `create_spr()`

このモジュールでは最大級の関数で、

- 画像ファイル選択
- 画像プレビュー
- 色数削減
- パレット表示
- 透明色選択
- スプライト名入力
- スプライト登録
- 一括取り込み

などをまとめて担当しています。

### `bulk_import()`

フォルダを指定すると、そのフォルダの画像を順番に `read_and_conv()` に渡してSPRパターンへ変換し、1つのスプライトセットとして返します。

------

# 9. ビットマップ書き出し

| 関数                            | 概要                                                         |
| ------------------------------- | ------------------------------------------------------------ |
| `dump_sprites(outdir, sprites)` | スプライトセットに含まれる有効なスプライトをPNG画像として一括出力 |

内部では、

```text
sprite_pattern()
    ↓
sprite_image()
    ↓
PNG保存
```

という処理を行っています。

------

# 10. 汎用サポート

| 関数                    | 概要                                                     |
| ----------------------- | -------------------------------------------------------- |
| `safeint(s, default=0)` | 通常の10進数・`0x`等の基数指定文字列を考慮して整数へ変換 |

`int(s)` に失敗した場合に `int(s, 0)` を試すことで、例えば `0xff` のような値も扱えるようにしています。

------
